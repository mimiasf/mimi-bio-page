# Mimi Bio Page

A static personal bio page for mimiasf.com.

## Structure

- `index.html` - page markup
- `css/styles.css` - page styling
- `js/script.js` - owner editor, uploads, audio player, and interactions
- `assets/media/background-small.mp4` - compressed page background video
